# Quarterly Hours Tracker v2.0

This folder contains the files for publishing the tracker with GitHub Pages.

## Upload to GitHub
1. Open the `switch-designs/Quarter-Hours-Tracker` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `.nojekyll`, and `README.md` from this package.
4. Commit the changes to the branch configured for GitHub Pages (usually `main`).
5. In **Settings → Pages**, confirm Pages is publishing from the intended branch and root (`/`).
6. Open the published Pages URL after the deployment finishes.

## Notes
- `index.html` is the tracker page GitHub Pages loads by default.
- This is a static web app. User-entered data is stored in the browser unless the app itself provides an export/backup feature. Back up important data regularly.
- Keep a separate copy of the Best Working Save and Restore 2 files; do not overwrite those backups.
